# 개발 과정과 AI 사용 기록

## 진행 과정

1. 과제 PDF를 바탕으로 C++17 어셈블러를 초기 생성했다. PDF의 스위치→LED 예제, 대표 인코딩과 오류 입력을 검사했다.
2. 별도 LED 테스트를 만들어 사용자가 CPUlator에서 성공 동작을 확인했다. 이 테스트는 `call`을 썼기 때문에 `jal label`의 버그는 드러나지 않았다.
3. 과제 제공 예제 4개를 사용해 파서의 누락 문법 3건과 `jal` 인코딩 오류 1건을 발견했다. 수정 후 사용자가 네 예제 모두 동작하는 것을 확인했다.
4. 18쪽의 선택 항목 중 일부 지시어와 주소 연산자를 추가한 뒤, RV32F 명령, 숫자 지역 라벨, 데이터 지시어, 매크로와 인클루드를 추가했다. 최종 제출 소스에는 이 변경 사항을 통합했다.

## 사용자 프롬프트

아래 인용은 대화에 입력한 사용자 요청이다. 첨부 파일 자체나 내부 실행 명령은 프롬프트로 취급하지 않았다.

**초기 생성**

> 나는 어셈블러를 구현하는 과제를 하는 중이야. 자세한 내용은 첨부 파일에 나와 있고 과제의 조건대로 동작하는 c++ 파일을 만들어줘.

**검증 예제 생성**

> 테스트 해보려면 실행파일로 만들어서 리다이렉션(<)으로 (.s) 파일을 표준 입력에 연결하면 되나? 그리고 어셈블러를 테스트할 수 있는 어셈블 코드를 만들어줘.

**과제 예제 진단 요청** (오류 메시지를 포함한 보고는 [검증 문서](verification.md)에 정리)

AI는 초기 소스 생성, 검증용 코드 작성, 오류 원인 분석과 수정, 기계어 비교 및 문서 초안 작성에 사용했다. CPUlator 실행 확인은 사용자가 수행했다.
