# 어셈블러 동작 상세

## 처리 흐름

1. 소스를 읽고 `.include`를 펼친다. `.macro`부터 `.endm`까지 본문을 저장하고 호출 시 `\인자명`을 치환한다. 매크로와 인클루드의 중첩 깊이는 32로 제한한다.
2. 숫자 지역 라벨 정의를 내부 고유 심볼로 바꾸고, `1b`·`1f`를 가장 가까운 해당 정의로 치환한다. 주석과 문자열 속 토큰은 참조로 해석하지 않는다.
3. 라벨과 피연산자를 분리하고 `.equ` 상수를 먼저 평가한다. 상수식에는 괄호, 단항 연산, 곱셈·나눗셈·나머지, 덧셈·뺄셈, 시프트, 비트 연산을 지원한다.
4. `.text`의 시작 주소는 `0x00010000`이다. `.data`와 `.bss`는 앞 구역 뒤의 16바이트 경계부터 배치한다. 심볼 값에 따라 `li`가 한 명령 또는 두 명령으로 바뀌면 배치를 다시 계산한다. `.bss`는 주소와 크기만 계산한다.
5. 최종 심볼 주소를 기준으로 명령과 데이터를 인코딩한다. 분기·점프의 라벨 피연산자는 현재 PC에 대한 변위로 변환하고 범위와 정렬 조건을 검사한다. `la`는 `auipc`와 `addi`, `ret`은 `jalr x0, 0(ra)`로 변환한다. 단일 피연산자 `jal label`은 복귀 주소를 `ra`에 쓴다.
6. 기계어와 데이터를 리틀엔디안으로 기록한다. `.lst`에 주소·인코딩·소스와 심볼을 표시한다. 파싱 또는 인코딩 오류 시 새 출력 파일을 만들기 전에 중단한다. 기존 출력 파일이 남아 있을 수 있으므로 실패한 실행 뒤에는 그것을 새 결과로 사용하지 않는다.

## 확장 기능과 제약

- `.rodata`는 raw 출력에서 `.data`에 합친다. `.section`은 `.text`, `.data`, `.bss`, `.rodata` 이름만 처리한다. `.string`은 `.asciz`의 별칭이고 `.set`은 재정의를 허용하지 않는 `.equ` 별칭이다.
- `.balign`, `.p2align`, `.org`는 단일 인자를 지원한다. `.org`는 섹션 시작 기준 오프셋이며 뒤로 이동할 수 없다. `%hi`와 `%lo`는 하위 12비트에 부호를 적용한 뒤 상위 값을 계산한다.
- `.dword`는 64비트 정수 데이터를, `.float`와 `.double`은 IEEE 754 단·배정밀도 데이터를 기록한다. `.double`은 D 명령 지원을 의미하지 않는다.
- F 명령은 적재·저장, 단정밀도 산술, FMA, 비교, 정수 변환, 비트 이동, 부호 조작, 분류와 관련 가상 명령을 지원한다. 반올림 모드를 생략하면 `dyn`이다.
- `.include`는 해당 소스를 처리 중인 디렉터리 기준으로 파일을 읽는다. 매크로는 고정 개수의 위치 인자를 받으며 기본값·가변 인자·중첩 정의는 지원하지 않는다. 전처리 이후 오류의 줄 번호는 확장된 소스 기준일 수 있다.
- D/A/C/H/Zicbom 명령, ELF/Intel HEX, 다중 오브젝트 링킹·재배치, `%pcrel_hi` 등은 미구현이다.
